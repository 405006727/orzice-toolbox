# Orzice Toolbox · 三角洲行动攻略工具 Windows 客户端

按攻略站 [orzice.com](https://orzice.com/)（三角洲小涛查 / 三角洲数据帝）左侧一级分类与二级功能整理的 Windows 桌面客户端。左侧导航与原站分类一一对应，内置可离线使用的本地小工具，其余行情、攻略类功能直达原站对应页面。

- 一级分类：9 个
- 功能项：47 项在线功能 + 3 项内置本地工具
- 完整清单见 [docs/feature-list.md](docs/feature-list.md)

## 运行环境

- Windows 10 / 11
- Python 3.10+（官方 Windows 安装包自带 tkinter，无需第三方运行库）

### 源码启动

双击 `run.bat`，或在项目目录执行：

```bat
python -m src.main
```

### 打包为 Windows 单文件 exe

双击 `build.bat`，或执行：

```bat
python -m pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name OrziceToolbox --add-data "data/features.json;data" main.py
```

产物位于 `dist/OrziceToolbox.exe`。

## 内置本地工具

- **今日密码门**：实时抓取原站首页六张地图（零号大坝、长弓溪谷、巴克什、航天基地、潮汐监狱、AZ3）当日密码，点击即可复制；抓取失败时使用内置参考密码兜底。
- **摩斯密码教程**：文本 ↔ 摩斯电码双向编解码，附标准字符码表。
- **物品单格价值计算器**：输入物品总价与占格数，计算单格平均价值并给出性价比参考。

其余功能为在线直达：客户端只保存分类与链接，价格、任务、图鉴等数据均在打开原站页面后由原站实时提供，客户端不缓存行情数据。
